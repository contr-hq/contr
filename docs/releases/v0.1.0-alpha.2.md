The second preview of the Contr core: the `contrd` daemon, the `contr` command line and the engine they run. The
desktop apps for Windows and Linux are released from their own repositories, built on this core. It is still an early
build; expect rough edges.

## What's new

**Compose and Kubernetes**

- Compose projects: the engine's containers are grouped by project, and `contr compose` lists projects, runs `up`,
  `down`, `restart` and the other project actions with the bundled Docker Compose, and shows their logs.
- Kubernetes: a single-node k3s cluster (v1.37.1 or v1.36.5, Traefik optional) runs on the engine, with a `contr`
  context in your kubeconfig. `contr kube enable`, `disable`, `reset`, `import` (copy local images into the cluster)
  and `use-context`. kubectl 1.37.1 is now among the Windows CLI tools.

**Windows engine settings**

- Proxy: the Windows proxy settings (including configuration scripts and automatic detection), a manual proxy, or
  none. The engine uses it, and new containers and builds can receive it too.
- The engine trusts the root certificates Windows trusts, so registries behind a company CA work.
- Docker Hub mirrors, and an editor for the engine's `daemon.json` that the engine checks before it is saved.

**Images and networks**

- Pulls and pushes use the credentials `docker login` stored, including credential helpers, so private registries
  work.
- Images can be tagged and pushed, and containers connected to and disconnected from networks.

**Linux**

- `contr-daemon` packages for Debian, Ubuntu and Fedora, from signed APT and DNF repositories at
  <https://contr-hq.github.io/contr-packages/> or as files below. They install the daemon's socket for every user.
- Without an engine, `contr fix install-engine` installs your distribution's own Docker Engine behind one password
  prompt (Ubuntu, Debian and Fedora); `contr fix join-docker-group` and `contr fix setup-rootless` give you access to
  an engine already there.

**Everywhere**

- `contr bundle` saves a diagnostics zip for support, with credentials and your name, home directory and computer
  name replaced.
- The daemon checks once a day for newer releases through your proxy, and `contr update` checks now. Turn it off with
  the `updates.check` setting; administrators can turn it off for everyone.
- The daemon stops at once when asked, even while apps are connected.
- The API grows to revision 21 with Compose, Kubernetes, update checks, diagnostics bundles, image tag and push, and
  network connect; the Rust and C# SDKs cover all of it.

## Verifying downloads

Every file carries a GitHub build attestation (`gh attestation verify <file> --repo contr-hq/contr`), and
`SHA256SUMS` is signed with the project's key at
<https://contr-hq.github.io/contr-packages/checksums/contr/v0.1.0-alpha.2/>. See
[Verifying downloads](https://github.com/contr-hq/contr/blob/main/docs/verifying.md) and the
[Code signing policy](https://github.com/contr-hq/contr/blob/main/docs/code-signing-policy.md).

## Known limitations

- The Windows executables are not code-signed yet, so Windows SmartScreen warns before they run, and Smart App
  Control may block them. Verify them as above.
- Builds are for x64 only.
- Installing WSL downloads it from Microsoft, and `contr fix install-engine` downloads from your distribution's
  mirrors.
